GitHub 로그인이 "GitHub 로 로그인(기기 코드)" 방식으로 바뀌었습니다. 더 이상 PC 마다 OAuth App 을 등록하지 않아도 됩니다.

## 바뀐 점
- **로그인**: [GitHub로 로그인] 을 누르면 화면에 8자리 코드가 보이고 브라우저에 `github.com/login/device` 가 열립니다. 브라우저에서 코드를 입력하고 승인하면 앱이 자동으로 로그인됩니다.
- **서버 설정**: GitHub OAuth App(Client ID·Client Secret) 항목이 없어졌습니다. 예전에 키체인에 저장한 Client Secret 은 앱을 시작할 때 지워집니다.

## 알아 둘 점
- 이미 로그인돼 있다면 업데이트 후에도 그대로 쓸 수 있습니다. 로그아웃한 뒤 다시 로그인할 때부터 새 방식입니다.
- 조직이 "승인한 OAuth App 만 허용"으로 돼 있으면, 그 조직의 저장소는 조직 관리자가 GitHub 의 **Third-party access** 에서 minmo 앱을 승인해야 보입니다. 예전에 직접 만든 OAuth App 의 승인과는 별개입니다.
- 원격 CLI 의 로그인(`minmo login <코드>`)은 바뀌지 않았습니다.
- 예전에 직접 만든 OAuth App 은 더 쓰이지 않으니 GitHub 설정에서 지워도 됩니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
