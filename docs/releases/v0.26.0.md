다른 PC 와 설정을 페어링 코드로 맞출 수 있습니다.

## 바뀐 점
- **설정 동기화(페어링 코드)**: 전역 설정의 "설정 동기화" 에서 서버 주소를 넣고 **코드 만들기** 를 누르면 10분 동안 1회 쓸 수 있는 코드가 나옵니다. 다른 PC 에서 같은 서버 주소와 코드를 넣고 **연결** 하면, 이후 1분마다 서로 맞춥니다.
  - 맞추는 것: 메모, 브랜치 이름 설정, 저장소 목록.
  - 맞추지 않는 것: 생성 후 스크립트, 작업 폴더 경로, 에이전트 실행 명령, 로그인 정보.
- **동기화 서버(`server-sync/`)**: 별도 Go 서버입니다. `cd server-sync && go run ./cmd/minmo-sync` 로 띄웁니다(기본 `127.0.0.1:8788`). 설치 파일에는 포함되지 않습니다.

## 알아 둘 점
- 기존 "다른 PC"(SSH·Tailscale) 동기화와는 따로 동작합니다.
- 두 PC 의 시계가 크게 다르면 어느 쪽이 새로운지 잘못 가릴 수 있습니다.
- 동기화 내용이 1MiB 를 넘으면 맞추지 못합니다.
- 연결을 끊어도 서버에는 기기 토큰이 남습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
