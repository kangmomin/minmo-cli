터미널에서 돌리는 코딩 에이전트가 지금 일하는 중인지, 끝났는지, 입력을 기다리는지 한눈에 볼 수 있습니다.

## 바뀐 점
- **에이전트 상태 표시**: 이슈의 터미널에서 Claude Code · Codex · Gemini CLI 를 돌리면 상태(작업 중 · 입력 대기 · 끝남 · 대기 중)를 보여 줍니다.
  - 트리의 이슈 행에 색 점, 터미널 패널 오른쪽 위에 에이전트 이름과 상태가 붙습니다.
  - 상단의 **에이전트 현황** 버튼에 작업 중·확인이 필요한 에이전트 수가 보입니다.
- **전체 현황**: 상단 버튼을 누르면 모든 이슈의 에이전트를 한 목록으로 봅니다. **필터**(상태·에이전트 종류·검색), **정렬**(급한 순·최근 활동·이름), **묶기**(저장소·상태·에이전트·호스트)를 고를 수 있고, 줄을 누르면 그 이슈의 터미널로 이동합니다. 고른 옵션은 저장됩니다.
- **알림**: 에이전트가 작업을 끝내거나 입력을 기다리게 되면, 그 터미널을 보고 있지 않을 때 Windows 알림을 띄웁니다. 서버 설정의 "에이전트 알림" 에서 끌 수 있습니다. 창을 트레이로 숨겨도 동작합니다.
- **트리 필터**: 사이드바의 로봇 버튼으로 에이전트가 있는 이슈만 볼 수 있습니다.
- 원격 호스트(tmux)의 터미널에서도 같은 방식으로 보입니다.

## 알아 둘 점
- 상태는 터미널 출력으로 **추정**합니다. Claude Code 와 Gemini CLI 는 창 제목으로 상태를 알려 주어 정확한 편이고, Codex 와 그 밖의 프로그램은 "출력이 4초 동안 없으면 끝난 것"으로 봅니다 — 오래 출력 없이 생각하는 동안에는 "끝남"으로 보일 수 있습니다.
- 빌드·개발 서버 같은 기타 프로그램은 전체 현황과 패널에만 보이고, 트리의 점과 알림에는 넣지 않습니다.
- 앱을 끄면 터미널이 끝나므로 현황도 사라집니다(원격 tmux 세션은 다시 열면 다시 감지합니다).
- tmux 를 쓰지 않는 원격 호스트에서는 Claude Code · Gemini CLI 만 감지됩니다(Codex 는 프로그램 이름을 알 수 없습니다).
- 하위 에이전트 목록과 minmo 에서 에이전트를 실행하는 기능은 다음 버전에 넣습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
