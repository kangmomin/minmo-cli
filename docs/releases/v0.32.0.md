앱이 배포된 서버에 바로 붙습니다. 설정 화면, 기본 작업 공간과 터미널 탭, 이슈 탭, 이슈 테이커, 답변 모드를 추가했습니다.

## 바뀐 점
- **배포된 서버 연결** (#117): 설치한 앱과 CLI 가 배포된 서버(`https://minmo-cli-production.up.railway.app`)에 붙습니다. 앱은 내장 서버를 띄우지 않습니다.
  - 경로·스크립트 설정은 PC 마다 따로 저장합니다. 전역 설정의 "경로·스크립트를 다른 PC 와 공유" 를 켜면 함께 씁니다(기본 꺼짐).
- **설정 화면** (#115): 상단 바의 설정 아이콘 4개를 ⚙ **설정** 하나로 합쳤습니다.
  - 전체 화면에서 분류(모양 · 알림·표시 · 에이전트 · 작업 공간 · 동기화 · 원격 호스트 · 원격 접속 · 원격 CLI · 서버·앱)를 고르고, 검색창으로 거릅니다.
  - 트리의 조직·저장소 ⚙ 는 그 범위의 작업 공간 설정을 바로 엽니다.
- **기본 작업 공간·터미널 탭** (#120): 트리 맨 위에 **기본** 이 생겼습니다. 저장소 없이 그 호스트의 홈 폴더에서 터미널을 씁니다.
  - 기본과 ★기타에는 터미널 탭이 있습니다. [+]·`Ctrl+T` 로 새 탭, 더블클릭·`F2` 로 이름 바꾸기, ×·`Delete` 로 닫습니다.
  - 다시 켜도 탭 목록과 이름이 남습니다. 원격 접속한 기기와 탭 목록을 함께 씁니다(고른 탭은 기기마다 따로).
- **이슈 탭** (#116): 작업 탭에 [이슈] 탭을 더했습니다. 이슈 본문을 마크다운으로 보입니다(읽기 전용).
  - 링크는 외부 브라우저로 엽니다. 이미지와 HTML 은 보이지 않습니다.
- **이슈 테이커** (#91): 저장소에서 켜 두면, 켠 뒤에 새로 열린 이슈마다 에이전트를 자동으로 실행합니다.
  - 기본은 `ready-for-impl` 로 요구사항을 정하고 이어서 `start-workflow` 로 구현하는 2단계입니다. 단계는 저장소마다 바꿉니다.
  - 트리에서 저장소를 우클릭해 **이슈 테이커…** 로 켭니다. 5분마다 확인하고, 동시에 3개까지 실행합니다.
  - 이슈 머리줄에 "자동 실행 i/n 단계" 와 [자동 실행 멈춤]·[자동 실행 다시 시도]·[이 단계부터 다시]·[다음 단계] 가 보입니다.
- **답변 모드** (#122): 상단 바의 [답변 모드] 를 켜면 답을 기다리는 에이전트 세션을 프로젝트 구분 없이 하나씩 보입니다.
  - 화면은 왼쪽 세션 목록, 위 요약 카드, 아래 그 세션의 터미널 하나입니다.
  - 답을 보내 에이전트가 다시 작업하면 2초 뒤 다음 세션으로 넘어갑니다. 에이전트가 끝나거나 패널을 닫아도 넘어갑니다. [건너뛰기]·[새 세션] 이 있습니다.
  - 자동으로 넘어간 뒤에는 키보드 포커스가 카드 제목으로 갑니다. 치던 글자가 다른 세션으로 가지 않습니다. `Tab` → [이 세션에 답하기] → `Enter` 로 그 터미널에 입력합니다.
  - 요약 카드에 Claude Code 마지막 답변과 Jev 판정(필요한 것·결과·급함)을 보일 수 있습니다. ⚙ 설정 → 서버·앱 → "세션 요약" 에서 켭니다.
- **★기타 worktree 삭제** (#119): ★기타 worktree 도 다른 이슈처럼 지울 수 있습니다.
- **터미널 프로세스 정리** (#100): 앱이 끝나거나 비정상 종료돼도 터미널의 ConPTY 호스트(OpenConsole·conhost)가 남지 않습니다.

## 알아 둘 점
- **업데이트한 뒤 한 번 다시 로그인해야 합니다.** 이 PC 의 내장 서버(`minmo.db`)에 있던 메모·설정은 배포된 서버로 옮기지 않습니다(파일은 남습니다).
- `MINMO_SOCKET` 없이 기본 소켓을 쓰던 CLI 는 배포된 서버로 바뀝니다. 다시 로그인하세요.
- PC 별로 저장하지 않은 설정 단계(전역·조직·저장소)는 함께 쓰는 값을 씁니다. 다른 PC 가 함께 쓰는 생성 후 스크립트를 바꾸면 이 PC 에서도 그 스크립트가 실행됩니다.
- ★기타에서 두 번째 `Ctrl+T` 는 새 패널이 아니라 새 탭을 만듭니다.
- ★기타 worktree 를 지우면 로컬 `etc` 브랜치도 지워집니다.
- 이슈 테이커는 이슈 글의 지시를 에이전트에 그대로 넣습니다. 공개 저장소에서는 작성자 범위를 넓히지 마세요. 설정은 이 PC 에만 있어서, 같은 저장소를 두 PC 에서 켜면 두 PC 가 모두 실행할 수 있습니다.
- Jev 판정은 버튼을 누를 때만 그 터미널의 마지막 글자(최대 200줄)를 TypeSafe(`api.typesafe.ai`)로 보냅니다. 기본은 꺼져 있고, API 키는 OS 키체인에 저장합니다.
- 앱을 끌 때 터미널을 하나씩 정리합니다. 터미널이 많으면 종료가 몇 초 늦어질 수 있습니다(8개에 약 3.5초).
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
