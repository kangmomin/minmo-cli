하단 바에 AI 별 사용량을 보이고, 저장소마다 연결 호스트를 정할 수 있습니다. 원격(SSH) 터미널의 첫 패널이 빈 화면으로 멈추던 문제를 고쳤습니다.

## 바뀐 점
- **하단 바의 AI 사용량**: 창 아래에 한 줄로 AI 별 사용량을 보입니다. 사이드바에서 고른 호스트(이 PC 또는 원격 호스트)의 값입니다.
  - **Codex**: 한도 사용률(%)을 보입니다. 예: `Codex 5h 34% 주 12%`. 80% 이상은 "높음", 100% 는 "한도 도달"을 붙입니다.
  - **Claude Code · Gemini CLI**: 오늘 쓴 토큰 수를 보입니다. 예: `Claude 1.2M 오늘`.
  - 값에 마우스를 올리면 상세(입력·출력·캐시 토큰, 한도 초기화 시각, 값의 기준 시각)를 보입니다.
  - 60초마다 다시 읽습니다. **서버 설정**의 "하단 바에 AI 별 사용량 표시"로 끕니다.
- **저장소별 연결 호스트**: **프로젝트 설정 → 연결 호스트**에서 저장소마다 호스트를 정합니다(`작업 호스트 따름` · `이 PC` · SSH 호스트).
  - 정한 저장소의 이슈는 사이드바의 작업 호스트와 관계없이 그 호스트에서 엽니다(worktree · 터미널 · 변경 · 파일).
  - 작업 호스트를 바꾸지 않고 SSH 저장소와 이 PC 저장소를 같이 씁니다.
  - 트리의 저장소에 호스트 배지가 붙습니다. 연결 전에는 이슈 목록 대신 연결 상태를 보입니다.
- **원격(SSH) 터미널의 첫 패널이 빈 화면으로 멈추던 문제를 고쳤습니다** (Windows): 터미널이 시작할 때 보내는 커서 위치 질의에 앱이 직접 답합니다. 화면이 늦게 연결되어도 출력과 입력이 멈추지 않습니다.

## 알아 둘 점
- 사용량은 그 컴퓨터에 있는 도구의 기록 파일을 읽은 값입니다. 그 컴퓨터에서 쓴 양만 셉니다(minmo 밖에서 쓴 양 포함). 기록 파일은 읽기만 합니다.
- Claude Code 의 한도 사용률(%)은 기록 파일에 없어 보이지 않습니다.
- Codex 의 % 는 Codex 를 마지막으로 쓴 시점의 값입니다. 초기화 시각이 지났으면 0% 로 보입니다.
- 토큰 수에는 캐시 읽기를 넣지 않습니다(상세에는 따로 보입니다).
- 원격 호스트의 사용량은 그 호스트에 `python3` 이 있어야 읽습니다. 없으면 "사용량을 읽을 수 없음(python3 필요)"을 보입니다.
- 기록 파일의 형식은 공개 규격이 아닙니다. 도구의 버전이 바뀌면 읽지 못할 수 있습니다.
- 원격 호스트에 묶인 저장소가 트리에 보이면 1번 자동으로 연결합니다. 실패하면 [다시 시도]를 누릅니다.
- 로컬 저장소(GitHub 가 아닌 폴더)에는 연결 호스트를 정할 수 없습니다.
- 사용량 표시와 연결 호스트는 데스크톱에만 있습니다. CLI 에는 없습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
