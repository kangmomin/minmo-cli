원격 호스트(SSH) 터미널의 연결이 끊겨도 같은 패널에서 자동으로 다시 접속합니다.

## 바뀐 점
- **연결이 끊기면 자동으로 다시 접속합니다**: 원격 터미널의 ssh 연결이 끊기면(네트워크 끊김·PC 잠자기 등) 같은 패널에서 2·4·8·16·30초 간격으로 최대 5번 다시 접속합니다.
  - 패널 아래에 "연결이 끊겼습니다. 다시 접속하는 중… (n/5)" 가 보입니다. [지금 재접속]을 누르면 기다리지 않고 바로 시도합니다.
  - 5번 모두 실패하면 "다시 접속하지 못했습니다" 와 [재접속]이 보입니다. 누르면 처음부터 다시 시도합니다.
  - 다시 접속하면 "다시 접속했습니다 (시각)" 이 3초 동안 보입니다.
  - 이전 출력은 그대로 남고, 그 아래에 `── 연결이 끊겨 다시 접속했습니다 (시각) ──` 한 줄이 들어갑니다.
  - `claude --resume` 같은 명령은 자동으로 입력하지 않습니다. 다시 접속한 뒤 직접 입력합니다.
  - 인증 실패나 호스트 키 변경처럼 다시 해도 안 되는 실패는 자동으로 시도하지 않고 원인을 바로 보입니다.
  - 원격 접속한 다른 기기(휴대폰·브라우저)도 같은 안내를 봅니다.
- **tmux 분할 패널의 세션도 남습니다**: "원격 터미널에 tmux 사용" 을 켠 경우, 분할로 만든 패널의 세션도 연결이 끊기거나 앱을 꺼도 남아 다시 붙습니다. 패널을 닫으면(Ctrl+W) 그 세션을 끝냅니다.
  - 첫 패널을 닫아도 남은 패널은 자기 세션을 계속 씁니다.

## 알아 둘 점
- 끊긴 동안 입력한 키는 원격으로 보내지 않습니다.
- 비밀번호·passphrase 를 묻는 접속은 자동 재접속을 지원하지 않습니다(키 파일 또는 ssh-agent 로 묻지 않고 접속되어야 합니다).
- 다시 접속한 뒤 창 크기를 바꾸면 화면에 보이던 이전 출력 일부가 지워질 수 있습니다. 위로 스크롤하면 남아 있습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
