설정 동기화(페어링 코드)에 배포된 서버 주소를 그대로 쓸 수 있습니다.

## 바뀐 점
- **배포된 서버로 설정 동기화** (#130): 배포된 서버(`https://minmo-cli-production.up.railway.app`)가 페어링 경로(`/pairs`)를 냅니다. 동기화 서버를 따로 띄우지 않아도 됩니다.
  - 첫 PC: ⚙ 설정 → 동기화에 이 주소를 넣고 **코드 만들기** 를 누릅니다.
  - 다른 PC: 같은 주소와 코드를 넣고 **연결** 을 누릅니다. 코드는 10분 동안 1회만 쓸 수 있습니다.
  - 페어 정보는 배포된 서버의 DB 에 저장합니다. 메인 로그인 세션이 아니라 페어 토큰으로 접근합니다.

## 알아 둘 점
- 이 기능은 서버 쪽 변경입니다. 서버는 이미 배포되어 있어서 v0.32.0 앱에서도 동작합니다. 앱 화면은 바뀌지 않았습니다.
- 배포된 서버를 쓰는 두 PC 는 메모와 함께 쓰는 설정을 이미 서버에서 함께 씁니다. 페어 동기화가 더 맞추는 것은 저장소 목록입니다.
- 같은 메모를 짧은 시간에 두 번 고치면, 페어 동기화가 메모에 "충돌 사본" 을 붙일 수 있습니다. 붙은 부분은 직접 지우세요.
- 별도 동기화 서버(`server-sync/`)는 `http://127.0.0.1` 주소로만 쓸 수 있습니다. 다른 주소는 앱의 CSP 가 막습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
