E2E 테스트 큐를 지웠습니다. 새 worktree 에 원본 폴더의 무시된 파일이 복사되지 않던 문제를 고쳤습니다.

## 바뀐 점
- **E2E 테스트 큐 제거** (#111): v0.30.0 에서 추가한 E2E 테스트 큐를 지웠습니다.
  - 상단 바의 [E2E 큐] 버튼과 이슈 머리줄의 [E2E 큐에 추가] 버튼이 없어집니다.
  - 이전 버전이 남긴 데이터를 지웁니다.
    - 역할 설정: 앱을 시작할 때 이 PC 의 설정과 공유 파일에서 지웁니다.
    - 결과 폴더(`.minmo/e2e/`): 이슈의 작업 폴더를 열 때 지웁니다. 원격 호스트의 작업 폴더도 지웁니다.
  - `.minmo/e2e/` 를 지운 뒤 `.minmo/` 가 비면 `.minmo/` 도 지웁니다. 다른 파일이 있으면 남깁니다.
- **무시된 파일 복사 수정** (#110): 새 worktree 를 만들 때 원본 폴더의 무시된 파일(`.env` 등)이 하나도 복사되지 않던 문제를 고쳤습니다.
  - 원인: 원본 폴더 경로가 얕으면(예: `D:\work\repo`) 복사를 거부했습니다.
  - 이제 원본은 메인 저장소 폴더 하나만 씁니다. 준비 기록에 복사한 수, 발견한 수, 제외한 수가 보입니다.

## 알아 둘 점
- `.minmo/e2e/` 라는 폴더를 다른 용도로 쓰고 있다면 작업 폴더를 열 때 지워집니다. 미리 옮겨 두세요.
- 원본 폴더(기준 저장소)를 지정하지 않은 GitHub 저장소는 무시된 파일을 복사하지 않습니다. 필요하면 저장소의 [기준 저장소 폴더] 를 지정하세요.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
