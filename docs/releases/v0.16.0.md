원격 접속 화면에서 Tailscale 을 설치하고, 로그인하고, HTTPS 주소까지 엽니다.

## 바뀐 점
- **Tailscale 도우미**: 상단의 **원격 접속** 대화상자에 **Tailscale** 영역이 생겼습니다. 상태에 따라 다음 할 일 하나를 버튼으로 보여 줍니다.
  - **설치 안 됨 → [Tailscale 설치]**: 실행할 명령을 먼저 보여 주고, 버튼을 누르면 Windows 패키지 관리자(winget)로 설치합니다. 설치 출력이 화면에 나오고 [취소] 할 수 있습니다. 끝나면 스스로 다음 단계로 넘어갑니다.
  - **로그인 안 됨 → [Tailscale 로그인]**: Tailscale 의 로그인 주소를 브라우저로 엽니다. 로그인을 마치면 화면이 스스로 "연결됨"으로 바뀌고, 이 PC 의 Tailscale 주소가 접속 주소에 나옵니다.
  - **연결됨 → [HTTPS 로 열기]**: `https://<PC 이름>.<tailnet>.ts.net` 주소를 만들어 접속 주소 맨 앞에 보여 줍니다. 기기 등록 QR 코드도 이 주소를 씁니다. 휴대폰의 "홈 화면에 추가"와 브라우저 알림에 필요합니다. [HTTPS 끄기] 로 닫습니다.
- 원격 접속을 끄면 minmo 가 연 HTTPS 도 함께 닫고, 포트를 바꾸면 새 포트로 다시 엽니다. 그 순간 Tailscale 이 꺼져 있어 맞추지 못했으면 [HTTPS 로 열기] 가 다시 나옵니다.

## 알아 둘 점
- **설치는 버튼을 눌렀을 때만** 합니다. 실행하는 명령은 `winget install --id Tailscale.Tailscale -e --source winget --accept-source-agreements --accept-package-agreements` 로 정해져 있고, 화면에 그대로 보입니다(창 없이 실행하므로 winget 의 동의 물음에 미리 답합니다). 설치 프로그램이 관리자 권한을 물을 수 있습니다.
- **macOS·Linux 는 명령만 안내합니다.** 설치에 관리자 암호가 필요해 앱이 대신 실행하지 않습니다(macOS: `brew install --cask tailscale-app`, Linux: 공식 설치 스크립트). winget 이 없는 Windows 에서는 [설치 페이지 열기] 를 쓰세요.
- **HTTPS 주소는 같은 tailnet 의 기기만** 열 수 있습니다(`tailscale serve`). 인터넷에 공개하는 기능(`funnel`)은 쓰지 않습니다.
- tailnet 에서 HTTPS 가 꺼져 있으면 [HTTPS 로 열기] 가 켜는 주소(Tailscale 관리 화면)를 안내합니다. 거기서 켠 뒤 다시 누르세요. 처음 접속할 때는 인증서를 받느라 몇 초 걸릴 수 있습니다.
- 이 PC 의 443 포트에 직접 걸어 둔 `tailscale serve` 설정(다른 경로·대상, `funnel` 로 인터넷에 연 것)이 있으면, 그 설정을 지우지 않도록 HTTPS 버튼을 내보이지 않습니다. 다만 전에 직접 `tailscale serve --bg http://127.0.0.1:<원격 접속 포트>` 로 걸어 둔 것은 minmo 가 건 것과 같아서, 앱이 HTTPS 주소로 보여 주고 원격 접속을 끄면 함께 닫습니다.
- HTTPS 설정은 앱을 끝내도 남습니다(Tailscale 이 기억합니다). 앱이 꺼져 있는 동안 그 주소는 응답하지 않을 뿐입니다. 없애려면 [HTTPS 끄기] 를 누르세요.
- [취소] 는 패키지 관리자를 끝냅니다. 이미 관리자 권한으로 넘어간 설치 프로그램은 끝까지 설치될 수 있습니다.
- Tailscale 계정 만들기, 기기 승인, 접속할 기기(휴대폰 등)에 Tailscale 앱을 설치하는 일은 직접 해야 합니다. 접속할 기기도 같은 계정으로 로그인하세요.
- 이 영역은 이 PC 의 창에서만 쓸 수 있습니다. 원격으로 붙은 기기는 설치·로그인·HTTPS 설정을 할 수 없습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
