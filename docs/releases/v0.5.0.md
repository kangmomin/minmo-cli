데스크탑 앱에서 SSH 프로필로 원격 호스트의 worktree·터미널을 직접 다룰 수 있습니다.

## 바뀐 점
- **원격 호스트(SSH 프로필)**: 사이드바 위의 **원격 호스트 관리** 에서 `~/.ssh/config` 의 Host 를 추가하고, **작업 호스트** 목록에서 고르면 그 호스트에서 이슈를 열고(worktree 생성) 터미널·변경·로컬 파일을 씁니다. 원격에는 git 만 있으면 되고, minmo CLI·역터널·로그인 코드는 필요 없습니다.
- **원격 터미널**: 원격에 tmux 가 있으면 전용 tmux 세션에 붙어, 앱을 끄거나 연결이 끊겨도 작업이 유지됩니다(원격 CLI 의 `minmo open` 과 같은 세션). 없으면 일반 로그인 셸로 엽니다.
- 열어 둔 이슈와 터미널은 다른 호스트를 보는 동안에도 유지됩니다.

## 준비물
- 터미널에서 `ssh <별칭>` 이 묻지 않고 접속되어야 합니다(키 또는 ssh-agent, 호스트 키 등록).
- 원격은 Linux·macOS 만 지원합니다.
- 비공개 저장소는 원격 자체의 git 자격 증명(`gh auth setup-git` 등)이 필요합니다.

## 알려진 제한
- Windows 의 OpenSSH 는 연결을 재사용하지 못해 원격 동작이 이 PC 보다 조금 느립니다.
- 원격 CLI 로 만든 worktree 는 앱에서 그 이슈를 열 때 이어받지만, 열기 전에는 ● 표시가 없습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
