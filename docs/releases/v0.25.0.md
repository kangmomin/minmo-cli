assign 된 이슈에 담당자가 보입니다. 앱에서 나에게 assign 할 수 있습니다.

## 바뀐 점
- **담당자 배지**: 담당자(assignee)가 있는 이슈는 트리의 이슈 줄과 이슈 머리줄에 `@login` 배지를 보입니다.
  - 이슈 줄: 여러 명이면 `@login +1` 로 보입니다. 마우스를 올리면 전체 목록이 보입니다.
  - 이슈 머리줄: 모든 담당자를 보입니다.
  - 내가 담당자인 이슈는 내 login 을 먼저 보이고, 배지 색이 다릅니다.
- **나에게 assign / 내 assign 해제**: 이슈 줄의 우클릭 메뉴와 이슈 머리줄의 버튼으로 바꿉니다. 다시 조회하지 않고 바로 배지가 바뀝니다.
  - 실패하면 오류 문구가 보입니다.

## 알아 둘 점
- assign 은 저장소에 쓰기 권한이 있어야 합니다. 권한이 없으면 `쓰기 권한이 필요합니다` 오류가 보입니다.
- 로컬 저장소의 작업과 ★기타에는 담당자가 없습니다.
- 다른 사람을 assign 하는 기능은 없습니다. 그것은 GitHub 에서 합니다.
- 다른 곳에서 바뀐 담당자는 새로고침 뒤에 보입니다.
- 이슈 목록의 순서는 바뀌지 않았습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
