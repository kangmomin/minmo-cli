저장소에 짧은 별칭을 달 수 있습니다. 사이드바의 폭을 끌어서 바꿀 수 있고, 긴 이름이 잘리지 않습니다. 이슈 행을 누르면 그 이슈의 터미널로 포커스가 갑니다. 터미널에서 링크를 열고 원격 프로그램의 복사를 받습니다. 터미널 잔상과 worktree 삭제 실패도 고쳤습니다.

## 바뀐 점
- **저장소 별칭**: **프로젝트 설정 → 별칭** 에 짧은 이름을 넣습니다. 비우면 원래 이름을 씁니다.
  - 트리·이슈 머리줄·에이전트 현황·알림·대화상자 제목에 별칭만 보입니다. 트리와 머리줄에서 마우스를 올리면 원래 이름이 보입니다.
  - **표시할 저장소** 대화상자에서 원래 이름과 별칭으로 찾습니다.
  - worktree 경로에 `{alias}` 를 씁니다. 별칭이 없으면 저장소 이름이고, 로컬 저장소는 폴더 이름입니다. 예: `~/work/{alias}/{branch}`
- **사이드바 폭 조절**: 사이드바 오른쪽 경계를 끌어 폭을 바꿉니다 (240~480px).
  - 키보드: 경계에 포커스하고 **←/→** (16px), **Home** (최소), **End** (최대) 를 누릅니다.
  - 경계를 더블클릭하면 기본 폭(288px)으로 돌아갑니다.
  - 폭은 이 PC 에 저장합니다.
- **사이드바 잘림을 고쳤습니다**: 긴 이름이 사이드바를 넓히지 않습니다.
  - 긴 이름은 한 줄로 줄이고 `…` 를 보입니다. 마우스를 올리면 전체 이름이 보입니다.
  - 오른쪽 버튼(+·⚙ 등)과 배지가 사이드바 밖으로 나가지 않습니다.
  - 버튼에 포커스해도 목록이 가로로 밀리지 않습니다.
- **이슈 행을 누르면 터미널로 포커스**: 이슈 행을 누르면 그 이슈에서 마지막으로 쓴 터미널 패널로 포커스가 갑니다. 바로 입력할 수 있습니다.
  - 조건: 작업 폴더가 준비됨, [터미널] 탭을 보는 중, 터미널이 떠 있음. 조건이 맞지 않으면 전과 같습니다.
  - 휴대폰에서 목록의 같은 이슈를 다시 누르면 작업 화면으로 갑니다.
- **터미널 링크 열기·복사**:
  - 터미널의 링크(`http`·`https`)를 **Ctrl+클릭** 으로 엽니다. ssh 원격 프로그램의 링크도 같습니다. 그냥 클릭하면 열지 않습니다.
  - ssh 원격 프로그램이 복사한 내용(OSC 52)이 이 PC 클립보드에 들어갑니다. 원격 프로그램은 이 PC 클립보드를 읽지 못합니다.
- **터미널 잔상·크기 멈춤을 고쳤습니다**: Claude 옵션 메뉴의 잔상이 남던 문제와, 클릭해야 터미널 크기가 패널에 맞던 문제입니다.
- **worktree 삭제가 계속 실패하던 문제를 고쳤습니다** (Windows): git 이 `node_modules` 의 junction 에서 멈추면 폴더가 반만 남았습니다. 이제 남은 폴더를 지우고 삭제를 끝냅니다.

## 알아 둘 점
- 별칭은 이 PC 에만 저장합니다. 원격 접속 화면(휴대폰·브라우저)과는 함께 씁니다. 서버·원격 CLI·다른 PC 와는 공유하지 않습니다. 다른 PC 에서는 `{alias}` 가 저장소 이름이 됩니다.
- 별칭을 바꾸면 worktree 경로도 바뀝니다. 이미 있는 worktree 는 그대로 쓰고 "경로 변경됨" 배지가 붙습니다.
- 사이드바 폭은 창 폭이 768px 이상일 때만 바꿉니다. 더 좁으면 경계가 숨습니다. 저장한 폭은 그대로입니다.
- 키보드 Enter 로 이슈를 열면 포커스가 터미널로 갑니다. 터미널에서 나가려면 Ctrl+Shift+M 을 누릅니다.
- 휴대폰(터치) 화면에서는 Ctrl+클릭을 할 수 없어 터미널 링크를 열 수 없습니다.
- 원격 프로그램이 마우스를 쓰면, 터미널에서 선택하려면 **Shift+드래그** 를 합니다.
- 창에 포커스가 없을 때 온 원격 복사(OSC 52)는 클립보드에 들어가지 않습니다.
- 앱을 새로 고치거나 호스트를 바꾼 뒤에는, 터미널을 클릭할 때까지 이전 크기로 남을 수 있습니다.
- worktree 삭제: 등록이 없는 경로에 git 이 아닌 일반 폴더가 있으면, 확인 대화상자에서 동의한 뒤에만 지웁니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
