Claude Code 가 띄운 하위 에이전트까지 에이전트 현황에서 볼 수 있습니다.

## 바뀐 점
- **하위 에이전트 현황**: 이슈의 터미널에서 도는 Claude Code 가 하위 에이전트를 띄우면, 그 종류·맡긴 일·실행 중인지를 보여 줍니다.
  - 터미널 패널 머리줄에 "하위 에이전트 N개 실행 중" 이 붙습니다.
  - 전체 현황에서 에이전트 줄 아래에 하위 에이전트 목록이 보입니다(실행 중인 것 먼저, 많으면 접힙니다).
  - 전체 현황에 "하위 에이전트 수" 정렬과 "하위 에이전트가 실행 중인 것만" 필터가 생겼습니다. 검색어는 하위 에이전트의 종류·설명에도 걸립니다.
- 원격 호스트의 Claude Code 도 같은 방식으로 보입니다.

## 알아 둘 점
- Claude Code 가 작업 폴더별로 남기는 세션 기록을 읽어 보여 줍니다. 공개된 규격이 아니라 Claude Code 버전에 따라 읽지 못할 수 있고, 그때는 상태(작업 중·끝남 등)만 보입니다. 사용자의 Claude Code 설정은 건드리지 않습니다.
- 같은 작업 폴더에서 Claude Code 를 여러 개 띄웠다면 가장 최근에 쓴 세션의 하위 에이전트만, 그 이슈의 첫 번째 Claude 패널에 보입니다.
- 끝났다는 표시 없이 30분 넘게 활동이 없는 하위 에이전트는 끝난 것으로 봅니다(세션이 중간에 끊긴 경우). 사용자가 멈춘 하위 에이전트도 끝난 것으로 봅니다.
- Claude Code 를 작업 폴더의 하위 폴더에서 실행했다면 보이지 않습니다.
- 앱에서 띄운 터미널의 Claude Code 가 쓰는 설정 폴더(`CLAUDE_CONFIG_DIR` 또는 `~/.claude`)를 봅니다. 터미널 안에서 다른 설정 폴더를 지정해 실행한 경우에는 보이지 않습니다.
- Codex · Gemini CLI 의 하위 에이전트는 지원하지 않습니다(상태만 보입니다).
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
