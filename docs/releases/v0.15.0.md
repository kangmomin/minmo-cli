등록한 PC 끼리 저장소 목록·설정·메모·에이전트 실행 명령을 맞춥니다.

## 바뀐 점
- **PC 사이 동기화**: **원격 접속** → **다른 PC** 에 PC 를 등록해 두면, 연결되자마자 한 번 그리고 1분마다 두 PC 를 맞춥니다. [지금 동기화] 로 바로 맞출 수도 있고, "등록한 PC 와 동기화" 를 끄면 맞추지 않습니다.
  - **메모**: 한쪽에만 있는 메모는 다른 쪽으로 가고, 같은 메모가 다르면 나중에 고친 쪽을 씁니다.
  - **설정**(전역·조직·저장소): 같은 방식으로 나중에 고친 쪽을 씁니다.
  - **저장소 목록**: 직접 추가한 GitHub 저장소를 서로 더합니다.
  - **에이전트 실행 명령**: 한쪽만 고쳤으면 그 값을 양쪽에 씁니다.
- **충돌 사본**: 같은 메모를 양쪽에서 고쳤다면(지난 동기화 뒤에 둘 다 고친 경우) 나중 것을 쓰되, 밀린 쪽 내용을 메모 끝에 "충돌 사본 — PC 이름, 시각" 으로 붙여 양쪽에 둡니다. 내용이 사라지지 않습니다.
- 다른 PC 목록에 마지막 동기화 시각, 주고받은 항목 수, 충돌 사본을 붙인 메모 수가 보입니다.

## 알아 둘 점
- 맞추지 않는 것: 로컬 저장소와 작업 폴더(그 PC 의 폴더입니다), SSH 호스트, 로그인 정보, 테마·글자 크기 같은 기기별 설정.
- **설정에는 경로가 들어 있습니다.** 작업 폴더 위치·생성 후 스크립트도 함께 맞춰지므로, 두 PC 의 폴더 구조가 다르면 `~` 로 시작하는 경로처럼 양쪽에서 통하는 값을 쓰세요. 생성 후 스크립트는 Windows 용과 Linux·macOS 용이 따로 있습니다.
- 저장소 목록은 **더하기만** 맞춥니다. 한 PC 에서 목록에서 뺀 저장소를 다른 PC 에서 빼지는 않습니다(다시 맞추면 뺀 PC 에 다시 생깁니다 — 양쪽에서 빼세요).
- 메모·설정을 지우는 기능은 없으므로 "지움"이 넘어가는 일도 없습니다. 메모를 비우면 빈 메모가 나중 것으로 넘어갑니다.
- 에이전트 실행 명령을 양쪽에서 서로 다르게 고쳤으면 각자 그대로 둡니다.
- "나중에 고친 쪽"은 각 PC 의 시계로 가립니다. 두 PC 의 시계가 크게 다르면 뜻밖의 쪽이 이길 수 있습니다(5분 넘게 앞선 시각은 받는 쪽이 지금 시각으로 고쳐 넣습니다).
- 동기화는 등록한 쪽이 합니다. A 에서 B 를 등록했으면 A 가 붙어 있는 동안 두 PC 를 맞춥니다. 두 PC 모두 v0.15.0 이상이어야 합니다(옛 버전이면 "동기화하지 못했습니다" 로 보입니다).
- 서로 다른 GitHub 계정으로 로그인한 PC 끼리도 등록·동기화가 됩니다. 메모와 설정은 각 PC 의 로그인 계정 아래에 들어갑니다 — 내 PC 끼리만 등록하세요.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
