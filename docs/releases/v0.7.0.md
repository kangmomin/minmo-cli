앱의 기본 색이 Ghostty 터미널의 기본 테마로 바뀌었습니다.

## 바뀐 점
- **Ghostty 테마(새 기본)**: Ghostty 를 설정 없이 켰을 때의 색(배경 `#282c34`, 글자 `#ffffff`, 기본 16색)을 앱 전체에 씁니다 — 터미널의 16색, 앱 화면(배경·사이드바·버튼·강조색), 파일 편집기의 문법 강조까지.
- 상단의 테마 버튼을 누를 때마다 **Ghostty → 블랙 → 라이트** 순으로 바뀝니다. 블랙·라이트 테마는 그대로 남아 있습니다.
- 업데이트하면 블랙을 쓰던 화면이 Ghostty 로 한 번 바뀝니다(블랙이 이전 기본값이었기 때문입니다). 라이트를 쓰고 있었다면 그대로이고, 블랙이 좋으면 테마 버튼으로 다시 고르면 유지됩니다.

## 알아 둘 점
- Ghostty 에 정해져 있지 않은 색(면·테두리·보조 글자)은 같은 계열에서 읽기 좋은 대비로 정했습니다. 오류 글자는 팔레트의 빨강을 조금 밝혀 씁니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
