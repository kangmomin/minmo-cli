호스트마다 작업 폴더의 위치를 정할 수 있고, 이슈가 많은 저장소에서 이슈를 검색할 수 있습니다.

## 바뀐 점
- **호스트별 기본 폴더**: 이 PC 와 원격 호스트마다 worktree 와 메인 clone 을 둘 폴더를 정합니다. 예: 한 호스트는 `/workspace`.
  - **데스크톱**: **원격 호스트** 대화상자의 "기본 폴더"에서 정합니다.
  - **CLI**: `minmo base-dir <경로>` 명령이 생겼습니다. `-` 는 해제합니다.
  - 경로 설정(worktree 경로·메인 clone 경로)이 `~/minmo-workspaces` 로 시작할 때 그 부분을 대신합니다.
  - 값은 그 기기에 저장하고 서버에 올리지 않습니다.
- **원본 위치(기준 저장소 폴더)를 더 쉽게 정합니다**: 이미 clone 해 둔 저장소 폴더에서 worktree 를 만드는 기능입니다.
  - **프로젝트 설정** 화면에 "원본 위치" 구역이 생겼습니다.
  - **CLI**: `minmo base-repo <owner/repo> <경로>` 명령이 생겼습니다. `-` 는 해제합니다.
  - 이 PC 의 창과 원격 접속한 기기(휴대폰·브라우저)가 같은 값을 씁니다.
- **이슈 검색**: 이슈가 10개보다 많은 저장소에는 목록 위에 검색 칸이 생깁니다. 번호(`42`, `#42`)와 제목으로 찾고, Esc 로 지웁니다.
- **작업 중인 이슈가 위에 옵니다**: 이슈 목록의 순서는 ★기타 → worktree 가 있는 이슈 → 나머지입니다. 각각 번호가 큰 것부터입니다.
- **[다시 실행]의 메인 clone 경로를 고쳤습니다**: worktree 를 만든 뒤에 경로 설정을 바꿔도, 생성 후 스크립트는 그 worktree 가 실제로 딸린 저장소 경로(`MINMO_MAIN_CLONE`)를 받습니다.

## 알아 둘 점
- 기본 폴더를 바꿔도 이미 만든 worktree 는 옮기지 않습니다. 바꾼 뒤 처음 여는 저장소는 새 위치에 메인 clone 을 다시 받습니다.
- 경로 설정의 앞부분을 다른 값으로 바꿨으면(예: `~/work/...`) 기본 폴더를 적용하지 않습니다.
- 원본 위치를 정한 저장소는 메인 clone 대신 그 폴더를 씁니다. 기본 폴더는 worktree 위치에만 적용됩니다.
- CLI 의 TUI 화면에서는 기본 폴더와 원본 위치를 바꿀 수 없습니다. 명령으로 바꿉니다.
- 이슈 검색은 불러온 목록(열린 이슈와 worktree 가 있는 닫힌 이슈, 최대 500개) 안에서만 찾습니다. 본문과 라벨은 보지 않습니다.
- worktree 를 만들거나 지우면 그 이슈의 줄 위치가 바뀝니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
