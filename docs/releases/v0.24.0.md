이슈 검색이 불러온 목록 밖의 이슈도 찾습니다. 이슈가 많은 저장소에서 검색에 안 나오던 이슈가 이제 나옵니다.

## 바뀐 점
- **이슈 검색이 GitHub 에도 묻습니다**: 앱은 저장소의 이슈를 최대 500개만 불러옵니다. 전에는 검색이 그 안에서만 찾았습니다. 이제 검색어를 치면 GitHub 에도 묻고, 목록에 없는 열린 이슈를 결과 아래에 붙입니다.
  - 입력을 멈추고 0.4초 뒤에 묻습니다. 찾는 동안 `GitHub 에서 찾는 중…` 이 보입니다.
  - 번호 하나(`42`, `#42`)를 치면 그 번호의 이슈를 직접 찾습니다.
  - 찾은 줄을 누르면, 검색어를 지워도 그 줄이 목록에 남습니다.
  - 실패하면 오류 문구와 **재시도** 버튼이 보입니다. 자동으로 다시 묻지 않습니다.

## 알아 둘 점
- GitHub 쪽 검색은 제목의 단어 전체가 맞아야 합니다. 예: 목록 밖의 이슈는 `log` 로 `login` 을 찾지 못합니다. 불러온 목록 안의 검색은 전과 같이 글자 일부로 찾습니다.
- 번호는 정확한 번호만 GitHub 에서 찾습니다. `4` 로 목록 밖의 `#42` 를 찾지 못합니다.
- GitHub 결과는 열린 이슈만, 최대 30개입니다. 본문·라벨은 보지 않습니다.
- "에이전트가 있는 이슈만" 을 켜면 GitHub 에 묻지 않습니다.
- 검색 칸은 보이는 이슈가 10개보다 많은 저장소에만 있습니다. 불러온 500개가 모두 닫힌 이슈나 PR 인 저장소에는 검색 칸이 없을 수 있습니다.
- 찾은 이슈는 worktree 를 만들지 않으면 새로고침 뒤에 목록에서 빠집니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
