저장소가 공개되었고, 데스크탑 앱이 스스로 업데이트하며, 원격 CLI 를 npm(GitHub Packages)으로 설치·업데이트할 수 있습니다.

## 바뀐 점
- **데스크탑 자동 업데이트**: 앱을 켜면 새 버전을 확인해 상단에 안내합니다. [설치하고 다시 시작]을 누르면 내장 서버를 정상 종료하고, 서명을 확인한 설치 파일로 업데이트한 뒤 다시 실행합니다. 서버 설정의 **앱 → 업데이트 확인** 으로 직접 확인할 수도 있습니다.
- **원격 CLI 를 npm 으로**: `@kangmomin/minmo-cli` 로 GitHub Packages 에 배포합니다. 명령이 끝날 때 새 버전이 있으면 알려 주고(하루 한 번 확인), `minmo update` 로 업데이트합니다.
- **릴리즈 자동화**: 태그를 올리면 GitHub Actions 가 설치 파일·업데이트 서명·CLI 배포까지 만듭니다.

## 설치
- **데스크탑**: `minmo_0.4.0_x64-setup.exe` 또는 `.msi`. v0.3.0 이하를 쓰고 있다면 이번 한 번만 직접 설치하면, 다음부터는 자동으로 업데이트됩니다.
- **원격 CLI(Ubuntu 등)**: `~/.npmrc` 에 GitHub Packages 레지스트리와 read:packages 토큰을 넣고 설치합니다.
  ```bash
  gh auth refresh -h github.com -s read:packages
  printf '@kangmomin:registry=https://npm.pkg.github.com\n//npm.pkg.github.com/:_authToken=%s\n' "$(gh auth token)" >> ~/.npmrc
  npm i -g @kangmomin/minmo-cli
  ```
  Node.js 22.12 이상이 필요합니다. 기존에 tgz 로 설치한 `minmo-cli` 는 `npm rm -g minmo-cli` 로 지운 뒤 설치하세요.

## 알려진 제한
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
- GitHub Packages 는 공개 패키지도 설치할 때 토큰이 필요합니다.
