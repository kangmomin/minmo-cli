원격 호스트에서 바로 작업할 수 있도록 네 가지를 더했습니다: 기존 폴더 가져오기, git 인증 전달, 파일 탭, 호스트 직접 등록.

## 바뀐 점
- **기준 저장소(기존 폴더 가져오기)**: 저장소 노드의 **기준 저장소 폴더** 에서 호스트에 이미 clone 해 둔 폴더를 지정하면, 새로 clone 하지 않고 그 저장소에서 이슈별 worktree 를 만듭니다. 그 폴더의 체크아웃은 건드리지 않습니다. 호스트마다 따로 지정하며 "이 PC" 에서도 쓸 수 있습니다.
- **원격 git 인증**: 앱이 원격에서 실행하는 clone·fetch·push 에 이 PC 의 GitHub 토큰을 그때그때 넘깁니다. 원격에 자격 증명을 설정하지 않아도 되고, 토큰은 원격의 디스크·git 설정·명령줄에 남지 않습니다.
- **파일 탭**: 작업 탭에 **파일** 이 생겼습니다. worktree 의 파일 트리를 보고 텍스트 파일을 편집합니다(문법 강조, Ctrl+S, 새 파일·새 폴더·이름 바꾸기·삭제). 이 PC 와 원격 모두에서 동작합니다.
- **호스트 직접 등록**: `~/.ssh/config` 없이도 **원격 호스트 관리 → 호스트 직접 등록** 에서 이름·주소·사용자·포트·키 파일을 넣어 저장합니다. 처음 접속하는 호스트는 [호스트 키 등록하고 연결] 로 등록합니다.

## 알아 둘 점
- 토큰 전달은 `https://github.com` 주소에만 적용됩니다. 터미널에서 직접 치는 `git push` 에는 적용되지 않습니다.
- 파일 탭은 2MB 이하의 UTF-8 텍스트만 엽니다. 저장 안 한 내용은 앱을 끄면 사라집니다.
- 호스트 등록은 키 파일·ssh-agent 만 지원합니다(비밀번호 접속 미지원).
- 기준 저장소에서 이미 체크아웃한 브랜치와 같은 이슈 브랜치는 만들 수 없습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
