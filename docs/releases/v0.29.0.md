조직·저장소·그룹 기준으로 새 창을 띄울 수 있습니다. 사이드바 이슈 목록을 에이전트 상태 순으로 정렬할 수 있습니다.

## 바뀐 점
- **새 창 보기** (#105): 같은 앱 화면을 창 하나 더 띄웁니다.
  - 트리의 조직·저장소·그룹 행에 마우스를 올리면 나오는 [새 창으로 열기] 버튼(우클릭 메뉴에도 있습니다), 상단 바의 [새 창] 버튼, `Ctrl+Shift+N` 으로 엽니다.
  - 조직·저장소·그룹에서 연 창은 그 범위만 보입니다. 처음에 그 노드가 펼쳐져 있습니다.
  - 창마다 지금 보는 이슈·펼친 노드·탭·사이드바 호스트가 따로 있습니다. 테마·알림 같은 설정은 모든 창에 같게 적용됩니다.
  - 터미널은 모든 창이 함께 씁니다. 같은 이슈를 두 창에서 열면 같은 터미널이 보입니다.
  - 에이전트 알림은 한 번만 뜹니다. 다른 창에서 그 이슈의 터미널을 보고 있으면 알리지 않습니다.
- **사용자 정의 그룹** (#105): 여러 조직의 저장소를 이름을 붙여 묶습니다.
  - 사이드바 상단의 [그룹 만들기] 버튼으로 만듭니다. 그룹은 트리 맨 위에 보입니다.
  - 그룹 행의 연필 버튼으로 이름·저장소를 고치거나 그룹을 지웁니다. 그룹을 지워도 저장소·설정은 지우지 않습니다.
  - 원격 접속한 기기(휴대폰·브라우저)도 같은 그룹을 봅니다.
- **에이전트 상태 순 정렬** (#98): 사이드바 상단의 정렬 버튼을 켜면 저장소마다 입력 대기 → 끝남 → 작업 중 → 대기 중 → 에이전트 없음 순으로 이슈를 보입니다. 설정은 저장됩니다.
- **새로고침 키 막기** (#99): `Ctrl+R`·`F5` 를 눌러도 앱이 새로고침되지 않습니다. 터미널의 `Ctrl+R`(셸 명령 기록 검색)은 그대로 동작합니다.

## 알아 둘 점
- 새 창은 앱을 다시 시작하면 복원되지 않습니다. 같은 범위로 다시 열면 창이 하나 더 뜹니다.
- 창 닫기 확인·트레이로 숨기기는 처음 창(주 창)만 합니다. 새 창은 닫기 버튼으로 바로 닫힙니다.
- 다른 PC 의 화면이나 원격 접속한 브라우저에서는 새 창 버튼이 보이지 않습니다.
- 그룹 안의 로컬 저장소는 폴더가 있는 호스트를 볼 때만 보입니다.
- 원격 화면(다른 기기의 브라우저)에서도 `F5`·`Ctrl+R` 이 막힙니다. 브라우저 주소창의 새로고침 버튼을 쓰세요.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
