GitHub 이슈를 minmo 안에서 등록할 수 있고, 에이전트 알림을 누르면 그 터미널로 갑니다.

## 바뀐 점
- **이슈 등록**: 브라우저를 열지 않고 GitHub 이슈를 만듭니다. 제목(필수)과 본문(선택, Markdown)을 넣습니다.
  - **데스크톱**: 저장소 줄의 **+** 버튼, 우클릭 메뉴의 **이슈 등록…**, 펼친 목록 맨 아래의 **+ 이슈 등록**.
  - **CLI**: `minmo new owner/repo "제목"` 명령이 생겼습니다. `-b 본문` 또는 `-b @파일` 로 본문을 넣고, `-e` 는 본문을 `$EDITOR` 로 씁니다. `--json` 은 결과를 JSON 으로 출력합니다.
  - **TUI**: 저장소 줄이나 이슈 줄에서 **i** 를 누릅니다. 제목 → 본문(한 줄) 순서로 입력하고 Esc 로 취소합니다.
  - 등록한 이슈는 목록에만 추가합니다. 선택은 바뀌지 않고 worktree 도 만들지 않습니다.
- **알림을 누르면 그 터미널로 갑니다**: 에이전트 알림(끝남·입력 대기)을 누르면 메인 창이 앞으로 오고(트레이로 숨겼거나 최소화했어도), 그 이슈의 터미널 탭이 열리고 해당 패널이 포커스를 받습니다.
  - 다른 PC 의 알림은 그 PC 의 창을 그 터미널로 엽니다.
  - 브라우저로 붙은 원격 화면의 알림도 같은 방식으로 이동합니다.
- **다시 붙은 터미널의 잔상을 고쳤습니다**: 휴대폰·브라우저로 붙거나 호스트를 바꾼 뒤, Claude Code 같은 전체 화면 프로그램에서 잔상·중복 줄이 남던 문제입니다. 붙을 때 화면 모드를 되살리고 프로그램이 화면 전체를 다시 그리게 합니다.

## 알아 둘 점
- 이슈 등록은 라벨·담당자·이슈 템플릿을 지원하지 않습니다.
- TUI 의 본문은 한 줄입니다. 여러 줄은 `minmo new -e` 를 쓰세요.
- 접힌 저장소에서 등록하면 저장소를 자동으로 펼치지 않습니다. 펼칠 때 목록을 불러옵니다.
- Windows 는 알림이 화면에 떠 있을 때의 클릭만 전달합니다. 알림 센터에 들어간 뒤의 클릭은 동작하지 않습니다.
- 알림을 누르기 전에 그 패널이 닫혔으면 이슈의 터미널 탭까지만 갑니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
