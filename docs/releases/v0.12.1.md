터미널에 편집 단축키 두 개를 더했습니다.

## 바뀐 점
- **Ctrl+Backspace**: 앞 단어를 지웁니다(PowerShell · bash · Claude Code · Codex).
- **Shift+Enter**: 전송하지 않고 줄을 바꿉니다(Claude Code · Codex 의 입력창).

## 알아 둘 점
- Shift+Enter 는 에이전트 CLI 의 입력창을 위한 키입니다. PowerShell 에서는 아무 일도 일어나지 않고, bash 등에서는 Enter 처럼 실행될 수 있습니다.
- Gemini CLI 에서의 동작은 확인하지 못했습니다.
- 한글을 조합하는 중에는 두 키를 가로채지 않습니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
